## A. 最大化 popcount

### 题意

构造一个长度为 $k$ 的非负整数序列 $a_1, a_2, \ldots, a_k$，满足：
- $\sum a_i \le n$
- 最大化 $\sum \operatorname{popcount}(a_i)$

输出可达的最大 popcount 之和。

### 解法

**核心贪心**：每个 $a_i$ 形如 $2^p-1$（即二进制低位全 1）时，能用最少的值换取最多的 1 的个数。

把整个过程看作逐层「升级」每一位。每个数一开始为 0（popcount = 0），第一次升级花费 $1$（$2^0$），获得第 0 位 → popcount +1；第二次升级花费 $2$（$2^1$），获得第 1 位；第三次花费 $4$，以此类推。因为有 $k$ 个数，每一层的升级名额有 $k$ 个。

因此逐层处理：
- 第 $j$ 层（$j = 0, 1, 2, \ldots$），每位成本 = $2^j$，共 $k$ 个名额。
- 若剩余预算 $n \ge k \cdot 2^j$：全部升级，`ans += k`，`n -= k * 2^j`。
- 否则：能升几个是几个，`ans += n / 2^j`，结束。

时间复杂度：$O(\log n)$ 每组数据。

### 参考代码（Python）

```python
def main():
    n = II()
    k = II()
    ans = 0
    p = 1
    while n > 0:
        if n >= k * p:
            n -= k * p
            ans += k
        else:
            ans += n // p
            break
        p <<= 1
    out.append(str(ans))
```

## B. AI Finds Nothing Here

### 题意

给定 $n \times m$ 的 0/1 矩阵。对于所有 $r \times c$ 子矩阵，要求其异或和为 0。问有多少种满足条件的矩阵，模 $998\,244\,353$。

### 解法

子矩阵异或和为 0 构成一组线性方程组（在 GF(2) 上）。每个 $r \times c$ 的滑动窗口给出一个方程，共有 $(n-r+1)(m-c+1)$ 个方程，且它们**线性无关**。

总共有 $n \cdot m$ 个变量（每个格子是 0 或 1），因此自由度为：

$$n \cdot m - (n-r+1) \cdot (m-c+1)$$

每个自由变量可取 0 或 1，因此答案为：

$$2^{\,n \cdot m - (n-r+1)(m-c+1)} \bmod 998\,244\,353$$

时间复杂度：$O(1)$ 每组数据（快速幂 $O(\log \text{exp})$）。

### 参考代码（Python）

```python
MOD = 998244353

def main():
    n = II()
    m = II()
    r = II()
    c = II()
    exp = n * m - (n - r + 1) * (m - c + 1)
    out.append(pow(2, exp, MOD))
```

## C. Alice and Bob

### 题意

Alice 和 Bob 轮流操作数组 $a$。每次操作必须选一个向量 $b$ 满足：
1. $0 \le b_i \le a_i$
2. $\sum b_i > 0$
3. $\bigoplus b_i = 0$

然后执行 $a_i \leftarrow a_i - b_i$。不能操作者输。问 Alice 第一步有多少种必胜选法，模 $998\,244\,353$。

### 解法

#### 游戏分析（SG 视角）

**必败态（SG = 0）**：正数元素个数 ≤ 1。

> 若只有 0 个或 1 个正数，无法构造满足 XOR = 0 且不全零的 $b$，因此无合法操作。

**必胜态（SG ≠ 0）**：正数元素个数 ≥ 2。

> 只需证存在一个后继是必败态。构造方法：
> 选定一个下标 $k$，设 $X_k = \bigoplus_{i \ne k} a_i$。令
> $$b_i = \begin{cases} a_i & i \ne k \\ X_k & i = k \end{cases}$$
> 若 $X_k \le a_k$，则操作后 $a'_i = 0 \; (i \ne k),\; a'_k = a_k - X_k$，正数个数 ≤ 1，对手进入必败态。
>
> - 若 $\bigoplus a = 0$：$X_k = a_k$ 对所有 $k$ 成立，取 $b = a$ 即清空全部，必败态。
> - 若 $\bigoplus a \ne 0$：由 Nim 基本定理，至少存在一个 $k$ 使 $X_k \le a_k$（取 total XOR 最高位对应的堆）。

由于对手一旦拿到 ≥2 个正数的局面必然也能反杀，Alice 的**所有**必胜第一步必定是那些「动手后对手只剩 ≤1 个正数」的操作。因此只需统计满足条件的 $k$ 的数量。

#### 计数公式

1. 若正数个数 < 2：无合法操作 → `0`
2. 若 $\bigoplus a = 0$：唯一的必胜操作是取走全部 → `1`
3. 否则：统计满足 $(xr \oplus a_k) \le a_k$ 的 $k$ 的数量

时间复杂度：$O(n)$ 每组数据，总 $O(\sum n)$。

### 参考代码（C++）

```cpp
void solve() {
    cin >> n;
    vector<int> a(n);
    for(auto &x: a) cin >> x;

    int xr = 0, pos = 0;
    for(auto x : a) {
        if(x > 0) pos++;
        xr ^= x;
    }
    if(pos < 2) { cout << "0\n"; return; }
    if(xr == 0) { cout << "1\n"; return; }

    ans = 0;
    for(auto x : a) if((xr ^ x) <= x) ans++;
    cout << ans << '\n';
}
```

## D. Round-Table Party

### 题意

$n$ 个人围坐一圈，每人有权重 $a_i$ 和视野范围 $d$（能看到顺时针和逆时针各 $d$ 人，共 $2d$ 个邻居）。选择一些人送礼，设 $S$ 为获得礼物的人集合：

- 若 $i \in S$：幸福值 = $($视野中没收到礼物的人数$) \cdot a_i$
- 若 $i \notin S$：幸福值 = $-($视野中收到礼物的人数$) \cdot a_i$

求最大总幸福值。

### 解法

设 $g_i = 1$ 表示第 $i$ 人收到礼物，$0$ 表示没有。$V_i$ 为 $i$ 的 $2d$ 个邻居集合。

总幸福值：

$$\begin{aligned}
H &= \sum_i g_i \cdot a_i \cdot \big(2d - \sum_{j \in V_i} g_j\big) + \sum_i (1-g_i) \cdot (-a_i) \cdot \sum_{j \in V_i} g_j \\[4pt]
&= 2d\sum_i g_i a_i - \sum_i a_i \sum_{j \in V_i} g_j \\[4pt]
&= 2d\sum_i g_i a_i - \sum_j g_j \sum_{i \in V_j} a_i \quad (\text{交换求和，} i \in V_j \Leftrightarrow j \in V_i) \\[4pt]
&= \sum_i g_i \Big(2d \cdot a_i - \sum_{j \in V_i} a_j\Big)
\end{aligned}$$

定义 $b_i = 2d \cdot a_i - \sum_{j \in V_i} a_j$，则 $H = \sum g_i b_i$。每个人的选择独立，最优策略就是选所有 $b_i > 0$ 的人送礼，答案为 $\sum \max(0, b_i)$。

**计算 $b_i$**：$V_i$ 是环形上 $[i-d, i+d]$ 去掉 $i$ 自己，用前缀和求区间和：

$$b_i = (2d+1)a_i - \text{sum}(i-d, i+d)$$

环形区间和用前缀和 + 分类讨论（`l > r` 时分两段）。

时间复杂度：$O(n)$ 每组数据，总 $O(\sum n)$。

### 参考代码（C++）

```cpp
void solve() {
    int d;
    cin >> n >> d;
    vector<i64> a(n);
    for(auto &x: a) cin >> x;

    vector<i64> pref(n + 1);
    for(int i = 0; i < n; i++) pref[i + 1] = pref[i] + a[i];

    i64 res = 0;
    for(int i = 0; i < n; i++) {
        int l = (i - d + n) % n;
        int r = (i + d) % n;
        i64 range_sum;
        if(l <= r)
            range_sum = pref[r + 1] - pref[l];
        else
            range_sum = pref[n] - pref[l] + pref[r + 1];
        i64 b = (2LL * d + 1) * a[i] - range_sum;
        if(b > 0) res += b;
    }
    cout << res << '\n';
}
```

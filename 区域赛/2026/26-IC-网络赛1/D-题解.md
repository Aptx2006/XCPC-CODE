# D 题解

## 题意

给定一个长度为 $n$ 的 01 串，定义

$$
p_i=\sum_{j=1}^{i}[s_i\ne s_j].
$$

也就是说，$p_i$ 表示在前 $i$ 个字符中，与 $s_i$ 不同的字符数量。

现在只给出 $p_1,p_2,\ldots,p_n$ 组成的多重集，不给出它们原来的顺序。求有多少个 01 串可以得到这个多重集，答案对 $998244353$ 取模。

题目保证至少存在一个合法字符串。

## 思路

### 1. 将字符串看成计数变化

扫描字符串，并设当前已经出现了 $x$ 个 `0`、$y$ 个 `1`。

- 如果下一个字符是 `0`，那么它对应的 $p_i=y$；
- 如果下一个字符是 `1`，那么它对应的 $p_i=x$。

所以每次加入一种字符，产生的数值就是另一种字符当前的数量。

### 2. 求两种字符的最终数量

注意到每一对不同的字符，都会在其中位置靠后的字符处被统计恰好一次。

假设整个字符串中有 $a$ 个 `0`、$b$ 个 `1`，其中 $a+b=n$，那么

$$
\sum_{i=1}^{n}p_i=ab=a(n-a).
$$

因此枚举较小的根 $a$，找到

$$
a(n-a)=\sum p_i
$$

即可得到两种字符数量的无序对

$$
\{a,n-a\}.
$$

代码从 $a=0$ 开始枚举，所以首先找到的一定是不超过 $n/2$ 的较小值。

### 3. 从小到大贪心重构

令 `c[k]` 表示多重集中数值 $k$ 还剩多少个。

假设当前两种字符已经分别出现了 $i$ 次和 `now` 次，并且

$$
i\le now.
$$

此时若继续加入数量较多的那种字符，新产生的 $p$ 就是 $i$。因此，剩余的所有 `c[i]` 都必须在当前阶段连续使用，使较多字符的数量变为

$$
now+c[i].
$$

一旦数量较少的字符从 $i$ 增加到 $i+1$，以后两种字符的数量都大于 $i$，就再也不可能产生数值 $i$，所以这里不能留下一部分 `c[i]` 以后处理。

如果 $i<a$，数量较少的字符还没有达到最终数量。接下来必须加入一个数量较少的字符，它产生的 $p$ 等于当前的 `now`，所以执行

```cpp
c[now]--;
```

然后较少字符的数量从 $i$ 变成 $i+1$，继续处理下一层。

### 4. 什么时候答案乘二

如果当前

$$
i=now,
$$

说明两种字符数量相等。此时下一个字符既可以是 `0`，也可以是 `1`，并且两种选择得到的无序计数状态完全相同，因此答案乘二。

一旦选择了其中一种字符，在下一次两种字符数量相等以前，数量较多和较少的字符身份都是确定的，不会产生额外选择。

循环结束时，较少字符已经出现 $a$ 次。剩余的 `c[a]` 只能用于增加另一种字符。如果此时 `now=a` 且 `c[a]>0`，最后一次从相等状态出发仍有两种选择，答案还要乘二。

因此，答案一定是若干个 $2$ 相乘得到的结果。

## 正确性证明

首先，每一对不同字符对答案 $\sum p_i$ 贡献一次且仅贡献一次，因此 $\sum p_i=ab$，算法能够正确求出两种字符最终数量的无序对。

假设处理数值 $i$ 前，两种字符的数量为 $i$ 和 `now`，其中 $i\le now$。产生数值 $i$ 的唯一方法是继续加入当前数量较多的字符。由于数量较少的字符一旦增加，两种字符数量都会大于 $i$，以后不可能再次产生 $i$，所以此时必须恰好使用所有剩余的 `c[i]`，算法的贪心操作是唯一可行的。

若 $i<a$，为了让较少字符最终达到 $a$ 个，下一步必须加入一次较少字符。它面对的不同字符数量正是此时的 `now`，所以必须消耗一个数值 `now`。题目保证输入合法，因此这个数值一定存在。

当两种字符数量不同时，较多字符和较少字符的身份已经确定，没有选择；当两种字符数量相同时，接下来选择 `0` 或 `1` 都会进入同一个无序状态，并对应两个不同字符串，所以方案数恰好乘二。算法统计了每次离开相等状态的两种选择。

由数学归纳法可知，算法在每一层都使用了唯一正确的多重集元素，并统计了全部且不重复的字符选择。因此最终得到的方案数就是合法 01 串的数量。

## 复杂度

- 时间复杂度：$O(n)$；
- 空间复杂度：$O(n)$。

## 其他可行算法

### 暴力枚举字符串

可以枚举全部 $2^n$ 个 01 串，计算每个字符串对应的 $p$ 多重集，再与输入比较，时间复杂度为 $O(n2^n)$，只能用于小规模对拍。

### 网格路径搜索

把 `0` 的数量看作横坐标，把 `1` 的数量看作纵坐标。加入 `0` 相当于走一条标号为当前纵坐标的横边，加入 `1` 相当于走一条标号为当前横坐标的竖边。

可以在网格上搜索所有能够消耗给定多重集的路径，但状态还需要记录各个数值的剩余次数，最坏复杂度仍然是指数级。主算法正是利用“最小坐标一旦增加就不会再次减小”的性质，把这种搜索压缩成了唯一的贪心过程。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

using i32 = int;
using i64 = long long;
using i128 = __int128;
#define all(x) (x).begin(), (x).end()
#define dbg(x) cerr << #x << " = " << (x) << endl;

int T = 1, n, m, k, ans, cnt;

const int mod = 998244353;

void solve() {
    cin >> n;
    vector<int> c(n + 1);
    i64 sum = 0;
    for (int i = 1, x; i <= n; i++) {
        cin >> x;
        c[x]++;
        sum += x;
    }

    int a = 0;
    while (1LL * a * (n - a) != sum) a++;

    i64 res = 1;
    int now = 0;
    for (int i = 0; i < a; i++) {
        if (now == i) res = res * 2 % mod;
        now += c[i];
        c[i] = 0;
        c[now]--;
    }
    if (now == a && c[a]) res = res * 2 % mod;
    cout << res << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```

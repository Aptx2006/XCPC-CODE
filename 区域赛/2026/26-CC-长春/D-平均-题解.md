# D. 平均 - 题解

## 题意

给定三个整数 $0\le a<b<c\le 2^{30}$，初始集合为 $S_0=\{a,b,c\}$。每一轮从上一轮集合中任取两个数，若平均值是整数，就将其放进新集合。允许取两个相同的数，因此 $S_i\subseteq S_{i+1}$。

有 $Q\le1000$ 次询问，每次给出目标 $t$：

- 若目标永远无法出现，输出 `-1`。
- 否则输出最小轮数 $k$，并进行恰好 $k$ 轮交互：当前目标为 $t$，输出两个数 $u,v$，满足 $u+v=2t$，且它们都能在剩余轮数内回到初始集合。交互器选择其中一个，作为下一轮目标。
- 最后一轮输出的两个数都必须属于 $S_0$，且最后一轮之后不读取交互回复。

题目保证：答案存在时，$k\le60$。

## 思路

### 1. 把平均过程展开成初始值的平均

先将三个初始值及目标同时减去 $a$，记为：

$$
0,\quad A=b-a,\quad B=c-a,\quad t'=t-a,
$$

其中 $0<A<B$。平移不改变平均关系，所以不改变答案。

注意到，连续做 $k$ 层二元平均，展开后就是 $2^k$ 个初始值的平均，初始值可以重复使用。

令 $N=2^k$。假设这 $N$ 个数里有 $p$ 个 $A$、$q$ 个 $B$，剩下的都是 $0$，那么：

$$
Ap+Bq=Nt',\qquad p,q\ge0,\qquad p+q\le N.
$$

最后一个条件表示剩余位置能用 $0$ 补满，不能漏掉。

因此，先解决这个问题：固定 $k$，能不能找到满足条件的 $p,q$？至于中间的平均值是否都是整数，后面会给出构造证明。

### 2. 扩展欧几里得求最合适的一组系数

记 $s=Nt'$、$g=\gcd(A,B)$。若 $g\nmid s$，本轮一定无解。

用扩展欧几里得求出：

$$
Ax+By=g.
$$

令 $M=B/g$，那么 $p$ 的最小非负解为：

$$
p_0=\left(x\cdot\frac{s}{g}\right)\bmod M,
$$

其中取模结果调整到 $[0,M-1]$。再代回原式，得到：

$$
q_0=\frac{s-Ap_0}{B}.
$$

为什么只检查这一组就够了？所有满足 $p\ge0$ 的整数解都形如：

$$
p=p_0+j\frac Bg,\qquad q=q_0-j\frac Ag,\qquad j\ge0.
$$

观察到，随着 $j$ 增大，$q$ 只会减小，而：

$$
p+q=p_0+q_0+j\frac{B-A}{g}
$$

只会增大。

因此，最小的非负 $p$ 已经是最值得检查的一组：

- 如果 $q_0<0$，其他解的 $q$ 更小，不可能合法。
- 如果 $p_0+q_0>N$，其他解占用的位置更多，不可能合法。
- 否则，这组系数合法。

从 $k=0$ 到 $60$ 依次检查，第一个成功的 $k$ 就是答案。若 $t\notin[a,c]$，则可以直接判无解，因为平均值不会超出初始值的范围。

### 3. 为什么总能保证中间的平均值也是整数

现在有 $N=2^k$ 个数，且它们的平均值是整数 $t'$。假设当前还剩 $2^r$ 个数，$r\ge1$，总和就是 $2^rt'$。

注意到：

- 总和为偶数，所以奇数的个数为偶数。
- 总个数为偶数，所以偶数的个数也为偶数。

因此，把奇数和奇数配对、偶数和偶数配对，就能保证每一对的平均值都是整数。

配完以后，个数、总和同时减半，上面的条件依然成立。由此不断配对，最后一定只剩一个数，且它就是 $t'$。

这就证明了：前面的系数条件既必要又充分。

### 4. 不展开全部叶子，始终只维护至多三组

虽然理论上有 $2^k$ 个数，但不能真的把它们全部存下来。我们只记录“这个数是什么，它有多少个”。初始时至多有三组：

$$
(0,N-p-q),\quad(A,p),\quad(B,q).
$$

每轮先按奇偶分组。对于同一个奇偶组，按以下方式配对：

1. 取出两组 $(u,c_u)$、$(v,c_v)$。
2. 配对 $\min(c_u,c_v)$ 次，得到相应数量的 $(u+v)/2$。
3. 至少一组会被用完，剩下的继续配对。
4. 如果最后只剩一组，其数量一定是偶数，直接自身配对即可。

若某个奇偶组原来有 $m$ 组，那么至多进行 $m-1$ 次不同组之间的配对，最后至多再进行一次自身配对，所以新产生的组数不超过 $m$。

由此可知，每轮的总组数都不超过三组。

### 5. 把配对过程记录下来，完成交互

每当把 $u,v$ 配成 $(u+v)/2$，就新建一个节点，并记录它的两个儿子是 $u,v$ 所在的节点。

相同节点出现很多次时，只记录次数，不复制整棵子树。这样每层至多新建三个节点，$60$ 层也只需要约 $180$ 个节点。

构造结束后，根节点的值就是目标。交互时：

1. 输出当前节点的两个儿子的值。
2. 交互器选择哪个值，就走到对应的儿子。
3. 重复恰好 $k$ 轮，最后到达初始叶子。

两个儿子值相同时，任选一个即可，因为它们都是合法的构造。

代码在构造树里直接保存原始值 $a,b,c$，因此输出时无需再加回平移量。

例如，初始集合为 $\{0,1,7\}$，目标为 $2$。取 $k=2$，可以使用四个叶子 $0,0,1,7$：先将 $(0,0)$ 配成 $0$，将 $(1,7)$ 配成 $4$，再将 $(0,4)$ 配成 $2$。倒过来就能完成交互：先输出 $0,4$，再根据回复输出 $0,0$ 或 $1,7$。

### 复杂度与实现细节

扩展欧几里得只预处理一次，耗时 $O(\log(c-a))$。每次询问枚举至多 $61$ 个轮数，构造和交互各 $O(k)$，因此每次询问 $O(60)$，额外空间 $O(60)$。

- $2^kt'$ 最大约为 $2^{90}$，相关计算必须使用 `__int128`。
- 数量最大为 $2^{60}$，使用 `long long` 足够。
- 每次输出都用 `endl` 刷新缓冲区。
- 最后一轮后不读取回复；答案为 `0` 或 `-1` 时也不进行交互。
- 即使途中选到初始值，仍然沿构造树走完剩余轮数，不能提前结束。

## 代码

使用题目请求中给出的 C++ 模板，仅增加辅助代码及 `solve()` 内容。编译标准为 C++17。

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64 = long long;
#define all(A) A.begin(), A.end()
#define dbg(A) cerr << #A << ':' << A << endl;
int n, m, k;

using i128 = __int128;

i64 exgcd(i64 a, i64 b, i64 &x, i64 &y){
    if(b == 0){
        x = 1;
        y = 0;
        return a;
    }
    i64 g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

struct Node{
    i64 val;
    int l, r;
};

void solve(){
    i64 a, b, c;
    if(!(cin >> a >> b >> c)) return;
    int Q;
    cin >> Q;

    // 平移后，初始值为 0, A, B，且 0 < A < B。
    i64 A = b - a, B = c - a;
    i64 x, y;
    i64 g = exgcd(A, B, x, y), mod = B / g;
    x = (x % mod + mod) % mod;

    auto check = [&](i64 t, int r, i64 &p, i64 &q){
        i128 len = (i128)1 << r, s = len * t;
        if(s % g != 0) return false;

        // p 取最小非负解，这时 p + q 也最小。
        p = (i128)x * ((s / g) % mod) % mod;
        i128 rem = s - (i128)A * p;
        if(rem < 0) return false;
        q = rem / B;
        return (i128)p + q <= len;
    };

    while(Q--){
        i64 t, p = 0, q = 0;
        if(!(cin >> t) || t == -1) return;
        int ans = -1;
        if(a <= t && t <= c){
            for(int r = 0; r <= 60; r++){
                if(check(t - a, r, p, q)){
                    ans = r;
                    break;
                }
            }
        }

        cout << ans << endl;
        if(ans <= 0) continue;

        // 每组保存 {节点编号, 出现次数}，无需真的展开 2^ans 个叶子。
        vector<Node> tr = {{a, -1, -1}, {b, -1, -1}, {c, -1, -1}};
        vector<pair<int, i64>> cur;
        i64 len = 1LL << ans;
        if(len - p - q) cur.push_back({0, len - p - q});
        if(p) cur.push_back({1, p});
        if(q) cur.push_back({2, q});

        for(int r = 0; r < ans; r++){
            vector<pair<int, i64>> group[2], nxt;
            for(auto [u, cnt] : cur){
                group[tr[u].val & 1].push_back({u, cnt});
            }

            for(auto &v : group){
                // 同奇偶的不同组尽量互相配对，直到其中一组用完。
                while(v.size() >= 2){
                    auto [u, cu] = v.back();
                    v.pop_back();
                    auto [w, cw] = v.back();
                    v.pop_back();
                    i64 cnt = min(cu, cw);

                    int id = (int)tr.size();
                    tr.push_back({(tr[u].val + tr[w].val) / 2, u, w});
                    nxt.push_back({id, cnt});
                    if(cu > cnt) v.push_back({u, cu - cnt});
                    if(cw > cnt) v.push_back({w, cw - cnt});
                }

                // 若还剩一组，其出现次数一定为偶数，直接自身配对。
                if(!v.empty()){
                    auto [u, cnt] = v.back();
                    int id = (int)tr.size();
                    tr.push_back({tr[u].val, u, u});
                    nxt.push_back({id, cnt / 2});
                }
            }
            cur = move(nxt);
        }

        int rt = cur[0].first;
        for(int r = ans; r >= 1; r--){
            int u = tr[rt].l, v = tr[rt].r;
            cout << tr[u].val << ' ' << tr[v].val << endl;
            if(r > 1){
                if(!(cin >> t) || t == -1) return;
                rt = (t == tr[u].val ? u : v);
            }
        }
    }
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1, r;
    //cin >> T;
    while(T--) {
        solve();
    }
    return 0;
}
```

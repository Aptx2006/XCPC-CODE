# J. Journey

## 题意

给定长度为 $2n$ 的序列 $a$，其中 $1\sim n$ 每个数恰好出现两次。

需要构造一个长度为 $2n$ 的合法括号序列 $s$。将每个下标看成一个点，连接两类边：

- 对于每一对匹配括号，连接它们所在的位置。
- 对于每一个数，连接它两次出现的位置。

要求最终所有 $2n$ 个点、$2n$ 条边恰好组成一个环。题目保证一定有解。

$2\le n\le 2\times 10^5$，所有测试的 $n$ 之和不超过 $2\times 10^5$。

## 思路

### 1. 从多个环开始

注意到，每个位置恰好属于一对匹配括号，也恰好属于一对相同数字，因此每个点的度数都是 $2$。所以只要整张图连通，就一定是一个包含所有点的环。

先令

```text
s = ()()()...()
```

此时括号边为 $(1,2),(3,4),\ldots,(2n-1,2n)$。再加入相同数字之间的边，整张图可能分成若干个环。如果两类边恰好连接同一对位置，就视作两条重边组成的小环。

接下来只需要不断将两个不同的环合并。

### 2. 将相邻的 `)(` 改成 `()`

考虑相邻的两个位置 $p,p+1$，它们当前分别是 `)` 和 `(`。

设位置 $p$ 原来与位置 $l$ 匹配，位置 $p+1$ 原来与位置 $r$ 匹配，那么

$$
l<p<p+1<r.
$$

交换这两个相邻括号后，原来的两条括号边

$$
(l,p),\quad(p+1,r)
$$

就变成了

$$
(l,r),\quad(p,p+1),
$$

其余括号的匹配关系不变。

观察到，交换只会让截至位置 $p$ 的前缀括号余额增加 $2$，其他前缀的余额都不变，因此整个序列仍然合法。

如果 $p,p+1$ 原来属于两个不同的环，删去这两条括号边后，两个环分别变成两条路径。新的两条边将两条路径的端点交叉连接，恰好合并成一个大环。

因此，我们只在两个位置属于不同连通块时交换，保证每次操作只会合并两个环。

### 3. 从左到右处理所有边界

从初始序列出发，依次考虑

$$
(2,3),(4,5),\ldots,(2n-2,2n-1).
$$

这些位置对互不重叠，所以轮到某一对时，它们仍然是初始的 `)(`。

使用并查集维护当前的连通块：如果两个位置在不同连通块，就合并它们，并交换这两个位置的括号。

下面说明最后一定连通：

- 初始的每对位置 $(1,2),(3,4),\ldots$ 都已经连通，后续操作只会合并连通块，因此它们始终连通。
- 每处理一个边界 $(2i,2i+1)$，都会保证这两个位置连通。

因此处理完之后，每两个相邻位置都处在同一个连通块，整张图必然连通。结合所有点度数为 $2$，最终恰好是一个大环。

### 4. 实现

相同数字所在的两个位置本来就有一条固定边，可以把它们当成一个点，因此并查集直接开在数字 $1\sim n$ 上。

初始将 `a[0],a[1]`、`a[2],a[3]` 等合并。之后依次检查 `a[1],a[2]`、`a[3],a[4]` 等，如果合并成功，就交换对应位置的括号。

并查集使用路径压缩和按大小合并，时间复杂度为 $O(n\alpha(n))$，空间复杂度为 $O(n)$。

代码保留模板的 `cin >> n >> m`，其中 `m` 暂存数组的第一个元素，再读入其余 $2n-1$ 个元素。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

using i32 = int;
using i64 = long long;
using i128 = __int128;
#define all(x) (x).begin(), (x).end()
#define dbg(x) cerr << #x << " = " << (x) << endl;

int T = 1, n, m, k, ans, cnt;

void solve() {
    cin >> n >> m;
    vector<int> a(2 * n), fa(n + 1), sz(n + 1, 1);
    a[0] = m;
    for(int i = 1; i < 2 * n; i++) {
        cin >> a[i];
    }
    iota(all(fa), 0);

    auto find = [&](int x) {
        while(x != fa[x]) {
            x = fa[x] = fa[fa[x]];
        }
        return x;
    };
    auto merge = [&](int u, int v) {
        u = find(u), v = find(v);
        if(u == v) return false;
        if(sz[u] < sz[v]) swap(u, v);
        fa[v] = u;
        sz[u] += sz[v];
        return true;
    };

    string s(2 * n, '(');
    for(int i = 0; i < 2 * n; i += 2) {
        s[i + 1] = ')';
        merge(a[i], a[i + 1]);
    }
    for(int i = 1; i + 1 < 2 * n; i += 2) {
        if(merge(a[i], a[i + 1])) {
            swap(s[i], s[i + 1]);
        }
    }
    cout << s << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for(cin >> T; T--; solve());
    return 0;
}
```

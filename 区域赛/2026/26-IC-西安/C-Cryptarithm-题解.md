# C. Cryptarithm

## 题意

给定长度为 $n$ 的整数序列 $a$ 和长度为 $m$ 的目标序列 $b$，初始序列 $c$ 为空，可以进行以下操作：

- 花费 $x$，将整个 $a$ 按顺序接到 $c$ 的末尾。
- 花费 $y$，将 $c$ 中的一个元素加一或减一。
- 花费 $z$，删除 $c$ 中的一个元素。

求将 $c$ 变成 $b$ 的最小总花费。

$1\le n,m\le 3000$，$0\le x,y,z\le 10^6$，$0\le a_i,b_i\le 10^9$。所有测试的 $nm$ 之和不超过 $9\times 10^6$，$n+m$ 之和不超过 $2\times 10^5$。

## 思路

### 1. 先把删除费用算进去

注意到，最终留下的元素一定来自若干份依次拼接的 $a$，并且相对顺序不变。保留下来的元素依次对应 $b_1,b_2,\ldots,b_m$，将 $a_i$ 改成 $b_j$ 的最小花费为 $|a_i-b_j|y$。

如果某一份 $a$ 的元素全部被删除，直接不粘贴这一份即可，费用不会增加。因此只需要考虑每份至少保留一个元素的方案。

直接计算每两个保留位置之间删除了多少元素比较麻烦。观察到，可以在粘贴一份 $a$ 时，先将这一份全部删除的费用也算进去，即花费

$$
W=x+nz.
$$

之后每保留一个 $a_i$ 来匹配 $b_j$，就退回一个元素的删除费，再加上修改费，额外费用为

$$
|a_i-b_j|y-z.
$$

假设总共粘贴了 $k$ 份，最后保留了 $m$ 个元素，统计的删除费用就是 $(kn-m)z$，与实际操作完全一致，最后一份的剩余元素也已经计算在内。

### 2. 动态规划

设 $f_j[i]$ 表示已经匹配 $b$ 的前 $j$ 个元素，且最后一个元素使用当前最后一份 $a$ 的第 $i$ 个位置时，按照上述方式统计的最小费用。

现在要用 $a_i$ 匹配 $b_j$，只有两类转移：

- 继续使用同一份 $a$。上一个位置必须满足 $p<i$，取 $\min_{p<i}f_{j-1}[p]$。
- 再粘贴一份 $a$。上一份最后使用的位置没有限制，取 $\min_p f_{j-1}[p]+W$。

由此可知

$$
f_j[i]=\min\left(\min_{p<i}f_{j-1}[p],\ \min_p f_{j-1}[p]+W\right)+|a_i-b_j|y-z.
$$

这两类转移覆盖了所有可能，相应费用也与实际方案一致，所以按 $j$ 递推即可得到最优解。答案为 $\min_i f_m[i]$。

### 3. 前缀最小值优化

对每一层从左到右枚举 $i$，用 `mn` 维护两个转移来源的最小值。先令

$$
\text{mn}=\min_p f_{j-1}[p]+W,
$$

处理完位置 $i$ 后，再将旧的 $f_{j-1}[i]$ 加入 `mn`。这样处理位置 $i$ 时，只会使用同一份中严格位于它之前的位置，每个状态就能 $O(1)$ 转移。

实现时可以原地滚动：先用 `tmp` 保存旧的 `f[i]`，计算新的 `f[i]`，再执行 `mn = min(mn, tmp)`。这个顺序不能交换，否则可能重复使用同一份的同一个位置。

初始化 `f[i]` 全为无穷大，`res = 0`。第一层的 `mn` 就是 $W$，对应先粘贴第一份，再选择任意位置。

时间复杂度为 $O(nm)$，空间复杂度为 $O(n)$。目标序列 $b$ 可以边读边处理，不需要保存。

### 4. 费用上界

即使每个目标元素都单独粘贴一份，费用也不超过

$$
m\bigl(x+(n-1)z+10^9y\bigr)
\le 3.000009\times 10^{18}.
$$

这个界也适用于各层的有限 DP 状态。转移时减去删除费之前，至多再多出一个 $z$，仍小于 $4\times 10^{18}$。

因此使用有符号 `long long` 足够，代码取 `inf = 4e18`。差值也用有符号类型计算，避免 `a[i] < b` 时发生无符号减法。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

using i32 = int;
using i64 = long long;
using i128 = __int128;
#define all(x) (x).begin(), (x).end()
#define dbg(x) cerr << #x << " = " << (x) << endl;

int T = 1, n, m, k, ans, cnt;

void solve() {
    cin >> n >> m;
    i64 x, y, z;
    cin >> x >> y >> z;
    vector<i64> a(n);
    for(auto &x: a) cin >> x;

    const i64 inf = 4e18;
    vector<i64> f(n, inf);
    i64 cost = x + n * z, res = 0;
    for(int j = 0; j < m; j++) {
        i64 b, mn = res + cost;
        cin >> b;
        res = inf;
        for(int i = 0; i < n; i++) {
            i64 tmp = f[i];
            f[i] = mn + llabs(a[i] - b) * y - z;
            mn = min(mn, tmp);
            res = min(res, f[i]);
        }
    }
    cout << res << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for(cin >> T; T--; solve());
    return 0;
}
```

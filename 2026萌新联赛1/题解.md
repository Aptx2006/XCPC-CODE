## A. 萌新大富翁

### 题意

$n$ 名玩家在 $m$ 个格子的环形棋盘上进行简化版大富翁玩家按编号循环行动，每轮使用一个骰子点数顺时针移动并触发落点效果格子类型包括：起点（+200）、地产（购买/交过路费）、幸运（+150）、惩罚（-100）、监狱（停牌一回合）金币不足时破产，地产清零并退出游戏游戏在所有骰子用完或只剩 1 人时结束输出每人最终金币和地产数

### 解法

纯模拟，按题意逐回合推进：

- 维护每个玩家的位置 `pos`、金币 `a`、停牌状态 `stop`、破产标记 `over`、地产列表 `house`
- 每轮：若玩家停牌则跳过（解除停牌）；否则掷骰子移动，根据格子类型处理效果
- 地产 op = 1：无主且金币够 → 强制购买；有主且非自己 → 支付过路费，不够则破产
- 幸运 op = 2：+150
- 惩罚 op = 3：金币不足 100 则破产，否则 -100
- 监狱 op = 4：停牌一回合
- 破产时地产清零、标记退出每轮结束后找下一个存活玩家，满足结束条件即退出

### 复杂度

$O(n + m + k)$，纯模拟

### 代码

```cpp
cin >> n >> m;
vector<i64> a(n);
for(auto &x: a) cin >> x;
vector<nod> e(m);
for(auto &[op, id, p, t]: e) {
    cin >> op;
    if(op == 1) cin >> p >> t;
}
cin >> k;
vector<i64> d(k);
for(auto &x: d) cin >> x;

vector<int> pos(n + 5);
vector<bool> stop(n + 5), over(n + 5);
vector< vector<int> > house(n + 5);

int cur = 0, q = 0;
cnt = n;

auto die = [&](int x) {
    a[x] = stop[x] = 0;
    over[x] = 1;
    cnt--;
    for(int y : house[x]) e[y].id = -1;
    house[x].clear();
};

while(cnt > 1 and q < k) {
    if(stop[cur]) {
        stop[cur] = 0;
    } else {
        pos[cur] = (pos[cur] + d[q++] % m) % m;
        auto &[op, id, p, toll] = e[pos[cur]];

        if(op == 0) {
            a[cur] += 200;
        } else if(op == 1) {
            if(id == -1 and a[cur] >= p) {
                a[cur] -= p;
                id = cur;
                house[cur].push_back(pos[cur]);
            } else if(id != -1 and id != cur) {
                if(a[cur] < toll) {
                    a[id] += a[cur];
                    die(cur);
                } else {
                    a[cur] -= toll;
                    a[id] += toll;
                }
            }
        } else if(op == 2) {
            a[cur] += 150;
        } else if(op == 3) {
            if(a[cur] < 100) die(cur);
            else a[cur] -= 100;
        } else {
            stop[cur] = 1;
        }
    }
    if(cnt == 1 or q == k) break;
    do {
        cur = (cur + 1) % n;
    } while(over[cur]);
}

for(int i = 0; i < n; i++) {
    if(over[i]) {
        cout << "bankrupt 0\n";
    } else {
        cout << a[i] << ' ' << house[i].size() << '\n';
    }
}
```

## B. 缝缝补补

### 题意

给定长度为 $n$ 的序列 $a$，选择一个正整数 $x$每次操作可对任意 $a_i$ 加上或减去 $x$，操作次数不限问能否使序列变成等差数列？求最大可行的整数 $x$

### 解法

设最终等差数列为 $b_i = A + i \cdot D$由于每次操作 $\pm x$ 不改变 $a_i \bmod x$ 的值，所以最终 $b_i \equiv a_i \pmod{x}$

取 $D = a_1 - a_0$，则 $a_i$ 应该等于 $a_0 + i \cdot D$定义：

$$\Delta_i = |(a_0 + i \cdot D) - a_i|$$

显然有：每个 $\Delta_i$ 必须能被 $x$ 整除

$$x = \gcd(\Delta_1, \Delta_2, \ldots, \Delta_{n-1})$$

若所有 $\Delta_i = 0$说明 序列原本就是等差数列

注意到：不论最终公差是什么，$a_0$ 和 $a_1$ 各自 $\pm x$ 操作后，差值满足 $D \equiv a_1 - a_0 \pmod{x}$，所以可以直接用前两项差作为 $D$ 即可

### 复杂度

$O(n)$，遍历一次求 gcd

### 代码

```cpp
cin >> n;
vector<i64> a(n);
for(auto &x: a) cin >> x;
i64 d = a[1] - a[0], ans = 0;
for(int i = 1; i < n; i++) {
    i64 ai = a[0] + i * d;
    ans = __gcd(ans, llabs(ai - a[i]));
}
cout << (ans? ans: -1) << '\n';
```

## C. 最大公约数

### 题意

给定序列 $a$，问有多少个子数组 $[l, r]$ 满足 $\gcd(a_l, \ldots, a_r) = \min(a_l, \ldots, a_r)$

### 解法

显然 $\gcd \le \min$ 所以 $\gcd = \min$ 当且仅当**最小值能整除区间内所有元素**

对每个元素 $a_i$，计算它能作为「最小且等于 $\gcd$」的区间个数，有以下几个限制：

**1. 必须是最小值**：用单调栈求出 $L[i]$ 和 $R[i]$（左边严格小于 $a_i$ 的第一个、右边严格小于 $a_i$ 的第一个），使得 $(L[i], R[i])$ 内没有比 $a_i$ 更小的数

**2. 必须是gcd**：用 $L\_[i]$ 和 $R\_[i]$ 表示 $a_i$ 能整除的最远左右边界这个地方很巧妙，想了很久，对于当前 $a_i$：

- 维护 $[L_[i], i]$ 整个区间 都可以被 $a_i$ 整除：从 $i$ 开始向左检查初始 `j = i`若 $a_{j-1} \bmod a_i = 0$，说明边界可以向左延伸，执行 `j = min(j - 1, L_[j - 1])`
  - 这里 `j - 1` 是朴素地往左走一步
  - $L\_[j - 1]$ 是位置 $j-1$ 已经算好的「左侧最远可被 $a_{j-1}$ 整除的位置」由于若 $a_i$ 能整除 $a_{j-1}$，而 $a_{j-1}$ 又能整除比它更左的所有数（即 $L\_[j-1]$ 左侧的所有数），那么 $a_i$ 也一定能整除它们（整除具有传递性），所以可以直接跳到 $L\_[j-1]$
  - 类似于并查集的**路径压缩**：一旦确认了从 $i$ 到 $j-1$ 的一段都是可被整除的，就不必逐个检查，直接跳跃，将 $O(n^2)$ 的查询优化成了近似 $O(n)$

- 对称地，从 $i$ 向右，若 $a_{j+1} \bmod a_i = 0$，则执行 `j = max(j + 1, R_[j + 1])`，原理同上

均摊后每个位置只被常数次跳跃访问，总复杂度 $O(n)$

**3. 数数**：注意我的 $L_[i]$ 和 $L\_[i]$ 分别是开区间和闭区间，左边界 $l = \max(L[i], \text{上次出现相同值的位置}, L\_[i] - 1)$，右边界 $r = \min(R[i], R\_[i] + 1)$则以 $a_i$ 为 「最小且等于 $\gcd$」 的区间数为：

$$(i - l) \times (r - i)$$

总答案即所有 $i$ 贡献之和

### 复杂度

均摊 $O(n)$，每个位置只会被跳跃访问常数次

### 代码

```cpp
cin >> n;
vector<int> a(n);
for(auto &x: a) cin >> x;
vector<int> L, R;
L = left_greater(a);
R = right_greater(a);
vector<int> L_(n), R_(n);
for(int i = 0; i < n; i++) {
    int j = i;
    while(j > 0 and a[j - 1] % a[i] == 0) {
        j = min(j - 1, L_[j - 1]);
    }
    L_[i] = j;
}
for(int i = n - 1; i >= 0; i--) {
    int j = i;
    while(j < n - 1 and a[j + 1] % a[i] == 0) {
        j = max(j + 1, R_[j + 1]);
    }
    R_[i] = j;
}
i64 ans = 0;
unordered_map<int, int> mp;
for(int i = 0; i < n; i++) {
    int last = -1;        
    if(mp.count(a[i])) {
        last = mp[a[i]];
    }
    mp[a[i]] = i;
    i64 l = max({L[i], last, L_[i] - 1});
    i64 r = min(R[i], R_[i] + 1);
    if(l <= i and i <= r) {
        ans += (i - l) * (r - i);
    }
}
cout << ans << '\n';
```

## D. 走迷宫

### 题意

$n \times m$ 的迷宫，从 `S` 到 `T`，可以上下左右移动有一次**穿墙机会**：可以将一面墙 `#` 当作空地通过，之后机会消失求最短步数，无法到达输出 $-1$

### 解法

分层图 BFS，把「是否用过穿墙」作为一个维

将状态表示为 $(x, y, use)$，其中 $use \in \{0, 1\}$ 表示是否已经使用过穿墙机会状态数 $2nm$

- 若下一步是空地 `.` 或终点 `T`：正常走，$use$ 不变
- 若下一步是墙 `#`：若 $use = 0$，可以穿墙，$use$ 变为 $1$；若 $use = 1$，不能再穿

从 $(sx, sy, 0)$ 开始 BFS，首次遇到 `T` 时的步数即为答案普通的 BFS 板子改改就能过，手快拿了首杀

### 复杂度

$O(nm)$，每个状态最多入队一次

### 代码

```cpp
int dx[] = {-1, 1, 0, 0};
int dy[] = {0, 0, -1, 1};

cin >> n >> m;
vector<string> G(n);
for(auto &x : G) cin >> x;
int sx = -1, sy = -1;
for(int i = 0; i < n; i++) {
    for(int j = 0; j < m; j++) {
        if (G[i][j] == 'S') {
            sx = i;
            sy = j;
        }
    }
}

int sz = n * m * 2;
vector<int> dis(sz, -1);
queue<int> q;

int st = (sx * m + sy) << 1;
dis[st] = 0;
q.push(st);

while(!q.empty()) {
    int u = q.front();
    q.pop();

    int use = u & 1;
    int cur = u >> 1;
    int x = cur / m;
    int y = cur % m;

    if(G[x][y] == 'T') {
        cout << dis[u] << '\n';
        return;
    }
    for(int d = 0; d < 4; d++) {
        int nx = x + dx[d];
        int ny = y + dy[d];
        if(nx < 0 or nx >= n or ny < 0 or ny >= m) {
            continue;
        }
        int nuse = use;
        if(G[nx][ny] == '#') {
            if (use) {
                continue;
            }
            nuse = 1;
        }
        int nst = ((nx * m + ny) << 1) | nuse;
        if (dis[nst] != -1) {
            continue;
        }
        dis[nst] = dis[u] + 1;
        q.push(nst);
    }
}
cout << -1 << '\n';
```

## E. 完美灵丝

### 题意

给定序列 $a$ 和参数 $K, D$，求满足以下条件的子数组个数：
- 不同元素个数**恰好**为 $K$
- 最大值 $-$ 最小值 $\le D$

### 解法

**差分转化**：设 $f(lim)$ = 不同元素个数 $\le lim$ 且极差 $\le D$ 的子数组个数则答案为：

$$f(K) - f(K-1)$$

**$f(lim)$ 的求解**：滑动窗口 + 单调队列

1. 右指针 $r$ 向右扩展，维护窗口 $[l, r]$：
  `cnt[]` 统计各值的出现次数，`num` 为不同元素个数
  单调队列维护窗口内**最小值**和**最大值**的索引
2.当窗口不合法（`num > lim` 或 `max - min > D`）时，收缩 $l$：
  弹出计数和过期的 deque 队首
3.累加合法区间数

### 复杂度

$O(n \log n)$（离散化排序），滑动窗口 $O(n)$

### 代码

```cpp
i64 d;
cin >> n >> k >> d;
vector<i64> a(n), b;
for(auto &x: a) cin >> x;
b = a;
sort(all(b));
b.erase(unique(all(b)), b.end());

vector<int> id(n);
for(int i = 0; i < n; i++) {
    id[i] = lower_bound(all(b), a[i]) - b.begin();
}

auto calc = [&](int lim) -> i64 {
    if(lim < 0) return 0;
    vector<int> cnt((int)b.size(), 0);
    deque<int> mn, mx;
    i64 res = 0;
    int l = 0, num = 0;
    for(int r = 0; r < n; r++){
        if(++cnt[id[r]] == 1) num++;
        while(!mn.empty() and a[mn.back()] >= a[r]) {
            mn.pop_back();
        }
        mn.push_back(r);
        while(!mx.empty() and a[mx.back()] <= a[r]) {
            mx.pop_back();
        }
        mx.push_back(r);

        while(l <= r and (num > lim or a[mx.front()] - a[mn.front()] > d)){
            if(--cnt[id[l]] == 0) num--;
            if(mn.front() == l) mn.pop_front();
            if(mx.front() == l) mx.pop_front();
            l++;
        }
        res += r - l + 1;
    }
    return res;
};

cout << calc(k) - calc(k - 1) << '\n';
```

## F. 闯关游戏

### 题意

$n$ 个关卡，$m$ 条前置规则 $u \to v$（必须先通关 $u$ 才能解锁 $v$）判断能否通关全部关卡，若能则输出字典序最小的闯关序列

### 解法

拓扑排序

把关卡看作有向图的节点，前置关系是边 $u \to v$若图中存在环则无法通关；

用**小根堆**求**字典序最小**的拓扑序即可

### 复杂度

$O(n + m)$，每条边和节点各处理一次

### 代码

```cpp
cin >> n >> m;
vector< vector<int> > G(n + 5);
vector<int> in(n + 5);
for(int i = 0, u, v; i < m; i++) {
    cin >> u >> v;
    G[u].push_back(v);
    in[v]++;
}
priority_queue<int> pq;
for(int i = 1; i <= n; i++) {
    if(in[i] == 0) {
        pq.push(-i);
    }
}
vector<int> out;
while(!pq.empty()) {
    int u = -pq.top();
    pq.pop();
    out.push_back(u);
    for(auto &v : G[u]) {
        in[v]--;
        if(in[v] == 0) {
            pq.push(-v);
        }
    }
}
if(out.size() != n) {
    cout << "No\n";
    return;
}
cout << "Yes\n";
for(auto &x: out) cout << x << ' ';
cout << '\n';
```

## G. 强迫症

### 题意

$n$ 棵树排成一排，高度为 $a_i$每次操作选一段连续区间，每棵树高度减 $1$（不能减成负数）求把所有树变成 $0$ 的最少操作次数

### 解法

把高度看作柱状图，每次操作对应在图上"切掉一层"从左边第一棵树开始：

- 第一棵树需要 $a_0$ 次操作来消除
- 对于第 $i$ 棵树（$i \ge 1$）：若 $a_i > a_{i-1}$，多出的高度 $a_i - a_{i-1}$ 需要**新增**操作（之前的操作区间无法覆盖）；若 $a_i \le a_{i-1}$，之前已经开始的操作已经能覆盖它，不需要新增

因此答案为：

$$a_0 + \sum_{i=1}^{n-1} \max(0,\ a_i - a_{i-1})$$

### 复杂度

$O(n)$，遍历一次

### 代码

```cpp
cin >> n;
vector<int> a(n);
for(auto &x: a) cin >> x;
i64 ans = a[0];
for(int i = 1; i < n; i++) ans += max(0, a[i] - a[i - 1]);
cout << ans << '\n';
```

## H. 神秘整数

### 题意

给定 $n$ 个互不相同的整数，求所有 $k > 1$ 使得所有 $a_i \bmod k$ 相等

### 解法

若所有 $a_i \bmod k = r$，则 $a_i - a_0$ 是 $k$ 的倍数因此 $k$ 必须整除任意两个数的差

设 $g = \gcd(a_1 - a_0,\ a_2 - a_0,\ \ldots,\ a_{n-1} - a_0)$，则 $k \mid g$

于是问题转化为：求 $g$ 的所有 $> 1$ 的因数若 $g = 1$，无解输出 $-1$

因数枚举：从 $2$ 到 $\sqrt{g}$ 枚举，若 $i \mid g$ 则加入 $i$ 和 $g/i$最后去重排序

### 复杂度

$O(n + \sqrt{g})$，$n \le 100$

### 代码

```cpp
cin >> n;
vector<i64> a(n);
for(auto &x: a) cin >> x;
i64 g = 0;
for(int i = 1; i < n; i++) {
    g = __gcd(g, llabs(a[i] - a[0]));
}
if(g == 1) {
    cout << "-1\n";
    return;
}
vector<i64> out{g};
for(i64 i = 2; i * i <= g; i++) {
    if(g % i != 0) {
        continue;
    }
    out.push_back(i);
    out.push_back(g / i);
}
sort(all(out));
out.erase(unique(all(out)), out.end());
for(auto &x: out) cout << x << ' ';
```

## J. 灵魂之塔

### 题意

给定序列 $a$，称一个序列「交替」当且仅当相邻元素奇偶性均不同问有多少个位置，删除该位置的元素后，剩余序列是交替序列

### 解法

显然我们只关心元素的奇偶性令 `a[i] = a[i] & 1`，统计相邻相同奇偶相同的数目 `cnt`

- 若 $n = 1$：按题目要求，特判输出 $1$
- 若 `cnt == 0`：序列已交替，只有删除**首元素**或**尾元素**能保持交替，答案 $2$
- 若 `cnt == 1`：存在一对相邻的元素奇偶性相同，删除这一对中任意一个都可以，答案同上
- 若 `cnt > 1`：至少两对不相交的冲突，删一个怎么都无法变成交替的，答案 $0$

### 复杂度

$O(n)$，遍历一次

### 代码

```cpp
cin >> n;
vector<i64> a(n);
for(auto &x: a) cin >> x, x = x & 1;
cnt = 0;
for(int i = 1; i < n; i++) {
    if(a[i - 1] == a[i]) cnt++;
}
if(n == 1) {
    cout << "1\n";
}else if(cnt <= 1) {
    cout << "2\n";
}else{
    cout << "0\n";
}
```

## L. 小明的丹药 (easy version)

### 题意

四种灵物各有若干份：
- 太阴：$+2$ 阴
- 少阴：$+1$ 阴
- 太阳：$+2$ 阳
- 少阳：$+1$ 阳

要求炼制「阴阳相等」的丹药，求最大总元素数 $=$ 阴 $+$ 阳

### 解法

贪心

设阴总量 $A = 2 \cdot aa + a$，阳总量 $B = 2 \cdot bb + b$理想情况下取 $\min(A, B)$ 份阴和阳即可，总数为 $2 \cdot \min(A, B)$

但：若 $a = 0$ 或 $b = 0$，则该部分只能产出**偶数**份元素此时若 $\min(A, B)$ 为奇数，需要减 $1$ 使其变为偶数

因此：

$$ans = \min(A, B)$$
$$\text{若 } a = 0 \text{ 或 } b = 0,\ \text{则 } ans -= (ans \bmod 2)$$
$$\text{答案} = 2 \cdot ans$$

### 复杂度

$O(T)$，每组 $O(1)$

### 代码

```cpp
i64 aa, a, bb, b;
cin >> aa >> a >> bb >> b;
i64 A = aa * 2 + a, B = bb * 2 + b;
i64 ans = min(A, B);
if(a == 0 or b == 0) {
    ans -= ans & 1;
}
cout << 2 * ans << '\n';
```

## M. 小明的丹药 (hard version)

### 题意

与 easy 版本类似，但各灵物的产出变为：
- 太阴：$+3$ 阴
- 少阴：$+2$ 阴
- 太阳：$+3$ 阳
- 少阳：$+2$ 阳

每种灵物 $\le 1000$ 份，$T \le 1000$求阴阳平衡时的最大总元素数

### 解法

背包 DP

问题转化为：阴侧和阳侧各自用 $3$ 和 $2$ 的权值，能否凑出某个总量 $x$

设 $sz = \min(aa \cdot 3 + a \cdot 2,\ bb \cdot 3 + b \cdot 2)$ 对四种灵物进行 01 背包：

- `dp[j]`：阴侧能否凑出恰好 $j$
- `dp_[j]`：阳侧能否凑出恰好 $j$

从大到小枚举 $j$，找到第一个 $j$ 使 `dp[j]` 且 `dp_[j]` 均可，答案 $= 2j$

注意到 $2$ 和 $3$ 可组合出除 $1$ 以外的所有正整数因此只要两侧各自至少有 $1$ 份 $2$ 单位灵物，答案就是 $2 \cdot \min(A, B)$（$\min \ge 2$ 时）
代码写的比较丑陋，如果用一个 lambda 函数实现 01背包，代码会好看很多

### 复杂度

$O(n \cdot sz)$，$sz \le 5000$

### 代码

```cpp
i64 aa, a, bb, b;
cin >> aa >> a >> bb >> b;
i64 sz = min(aa * 3 + a * 2, bb * 3 + b * 2);
vector<bool> dp(5005), dp_(5005);
dp[0] = 1;
for(int i = 0; i < aa; i++) {
    for(int j = sz; j >= 3; j--) {
        dp[j] = dp[j] or dp[j - 3];
    }
}
for(int i = 0; i < a; i++) {
    for(int j = sz; j >= 2; j--) {
        dp[j] = dp[j] or dp[j - 2];
    }
}
dp_[0] = 1;
for(int i = 0; i < bb; i++) {
    for(int j = sz; j >= 3; j--) {
        dp_[j] = dp_[j] or dp_[j - 3];
    }
}
for(int i = 0; i < b; i++) {
    for(int j = sz; j >= 2; j--) {
        dp_[j] = dp_[j] or dp_[j - 2];
    }
}
for(int i = sz; i >= 0; i--) {
    if(dp_[i] and dp[i]) {
        cout << 2 * i << '\n';
        return;
    }
}
```

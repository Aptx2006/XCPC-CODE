为了让你彻底弄明白这道题，我们从**生活直觉**出发，一步步拆解：
1. **笛卡尔树到底是什么？**
2. **怎么判断两个区间的笛卡尔树“长得一模一样”？**
3. **为什么这个问题可以转化为字符串匹配（KMP）？**

---

### 第一步：用“单调栈”看笛卡尔树的本质

先回顾笛卡尔树的标准建树过程（从左往右插入）：
维护一个单调递增的栈（栈底小、栈顶大）。每来一个新数字 $x$：
1. 它会把栈顶所有**大于**它的数字全部**弹出**（这些被弹出的节点变成 $x$ 的左子树）。
2. 弹完之后，如果栈里还有元素，此时的栈顶元素就是 $x$ 左边**第一个 $\le x$ 的数**（$x$ 会成为这个栈顶的右孩子）。
3. 如果栈空了，说明 $x$ 是当前子区间内的全局最小值（成为整棵树的新根）。

**关键发现**：
每次新加入一个元素时，这棵树的结构变化**只由一件事决定**——**它弹出了左边的多少个元素**（或者说，它左边第一个 $\le x$ 的元素离它有多远）。

---

### 第二步：定义距离 $c[i]$

定义 $c[i]$ 为：在全局数组中，**$a[i]$ 距离它左边第一个 $\le a[i]$ 的位置的距离**。
- 如果左边没有更小的，相当于一直到下标 $0$，距离就是 $i - 0 = i$。

比如数组 `[2, 1, 3, 1, 2]`：
- $i=1, a[1]=2$：左边没有更小的 $\to c[1] = 1 - 0 = 1$
- $i=2, a[2]=1$：左边没有更小的 $\to c[2] = 2 - 0 = 2$
- $i=3, a[3]=3$：左边第一个 $\le 3$ 是 $a[2]=1$ $\to c[3] = 3 - 2 = 1$
- $i=4, a[4]=1$：左边第一个 $\le 1$ 是 $a[2]=1$（题目要求最小值相同取最左，所以小于等于即可）$\to c[4] = 4 - 2 = 2$
- $i=5, a[5]=2$：左边第一个 $\le 2$ 是 $a[4]=1$ $\to c[5] = 5 - 4 = 1$

得到序列 $c = [1, 2, 1, 2, 1]$。

---

### 第三步：局部区间内的“截断”

如果我们只考虑一个**长度为 $k$ 的局部子区间**，这个区间最后一个元素往左找更小的数时，**视线不能超出这个子区间的左边界**。

- 如果它往左找更小数的距离 $c[i] \le k$，说明在区间内部就能找到更小的数，有效距离就是 $c[i]$。
- 如果 $c[i] > k$（或者区间内根本没有更小的数），它的视线会被区间的左边界挡住，所以有效距离最多只能是 $k$。

因此，在一个长度为 $k$ 的子区间中，末尾元素的建树行为完全由：
$$\min(c[i], k)$$
这个数值唯一决定！

**核心定理**：
两个子区间 $[l_1 \dots r_1]$ 和 $[l_2 \dots r_2]$ 的笛卡尔树同构，**当且仅当**对于区间内的每一个相对位置 $k$（$1 \le k \le \text{长度}$）：
$$\min(c[l_1 + k - 1], k) == \min(c[l_2 + k - 1], k)$$

---

### 第四步：转化为 KMP 的 `next` / $\pi$ 数组

题目要求：
> 对每个 $i$，求最长的 $j < i$，使得 $CT(a_{1 \dots j})$ 与 $CT(a_{i-j+1 \dots i})$ 同构。

这正是经典 KMP 算法中求 **前缀函数 $\pi[i]$（最长公共真前后缀）** 的定义！

在普通字符串 KMP 中：
- 我们比较字符：`s[j + 1] == s[i]`

而在笛卡尔树匹配中：
- 当前匹配的长度是 $j$，现在尝试把长度拓展为 $j + 1$。
- 根据上面的核心定理，新加入的这个位置需要比较两边的**局部有效距离**是否一致：
  $$\min(c[j + 1], j + 1) == \min(c[i], j + 1)$$

如果相等：
- 匹配成功，$j \leftarrow j + 1$。

如果不相等：
- 匹配失败，利用 KMP 的前缀表回跳：$j \leftarrow \pi[j]$，继续尝试，直到匹配或 $j = 0$。

---

### 整个算法的执行步骤总结

1. **单调栈预处理**：$O(n)$ 时间算出全局每个元素的 $c[i]$。
2. **跑 KMP**：$O(n)$ 时间计算 $\pi$ 数组，每次比较用 $\min(c[j+1], j+1) == \min(c[i], j+1)$。
3. **输出**：$\pi[1 \dots n]$ 即为各位置的答案。

每个元素进出栈一次、KMP 指针回跳总次数不超过 $O(n)$，因此总时空复杂度均为完美线性的 $O(n)$。

# A Recall 题解

## 题意

有一个初始为空的栈，原操作共有三种：

- `+ x`：把 $x$ 压入栈中；
- `? x`：询问 $x$ 是否在栈中，记录为 `T x` 或 `F x`；
- `-`：弹出栈顶元素。

现在所有 `-` 操作都丢失了，只剩下 `+ x`、`T x` 和 `F x`。我们需要在适当位置重新插入若干个 `-`，满足：

- 栈中任意时刻没有重复元素；
- `T x` 查询时 $x$ 在栈中；
- `F x` 查询时 $x$ 不在栈中。

输出一种合法操作序列，其中原来的 `T` 和 `F` 都输出为 `?`。题目保证至少存在一种合法方案。

## 思路

### 1. 为每次入栈建立存活区间

注意到，一个元素只有在成功查询 `T x` 时才被要求留在栈中。

对于每次 `+ x`，建立一个编号，并记录：

- `l[id]`：这次入栈的位置；
- `r[id]`：在下一次 `+ x` 以前，最后一次 `T x` 的位置。

如果这次入栈后没有成功查询，初始令

$$
r[id]=l[id].
$$

读到 `T x` 时，使用哈希表找到 $x$ 最近一次入栈的编号，并更新

$$
r[id]=i.
$$

题目保证存在合法方案，所以每个 `T x` 一定对应当前有效的某次 `+ x`；而 `F x` 不要求任何元素继续留在栈中，不需要参与区间构造。

### 2. 用栈确定实际出栈位置

按照操作顺序扫描所有入栈区间。到达 `l[id]` 时，把这个编号压入辅助栈。

如果栈顶区间满足

$$
r[id]\le i,
$$

说明它要求保留到的最后一次成功查询已经完成，现在可以立即弹出。

弹出一个区间后，新的栈顶可能也早已完成全部成功查询，因此继续弹出，直到栈顶仍然需要留到未来为止。每弹出一个编号，就在 `del[i]` 中记录当前位置需要输出一个 `-`。

这相当于给每次入栈选择最早的合法出栈时间。

### 3. 去掉原代码中不必要的排序

给出的参考代码先修改每个区间的右端点，再排序所有右端点，以统计每个位置输出多少个 `-`。

实际上，辅助栈弹出一个编号时，我们已经知道它会在当前位置 $i$ 出栈，直接执行

```cpp
del[i]++;
```

即可。因此不需要最后的排序。

同时，使用 `unordered_map` 代替 `map` 后，整个算法的期望时间复杂度可以从 $O(n\log n)$ 降为 $O(n)$。

## 正确性证明

对于一次编号为 `id` 的入栈，区间 $[l[id],r[id]]$ 包含了这次入栈以后所有需要它存在的 `T` 查询。因此在 $r[id]$ 以前不能弹出它，而在 $r[id]$ 以后不再有查询要求这次入栈的元素存在。

扫描到位置 $i$ 时，如果栈顶满足 $r[id]\le i$，那么它所有必须存在的时刻都已经结束，立即弹出不会影响任何成功查询。若栈顶满足 $r[id]>i$，它在未来仍然需要被查询为存在，因此不能弹出；由于栈只能从顶部删除，它下方的元素也暂时不能弹出。故算法每次弹栈都是安全且必要的最早弹栈。

如果再次出现 `+ x` 或出现 `F x` 时旧的 $x$ 仍未弹出，那么旧的 $x$ 上方一定存在某个尚未结束的区间。为了删除旧的 $x$，任何方案都必须同时弹出这个仍需成功查询的元素，从而不可能合法。这与题目保证存在合法方案矛盾。因此在合法输入中，旧的 $x$ 一定已由算法提前弹出，所有重复入栈与失败查询均满足要求。

成功查询 `T x` 已被计入对应入栈区间的右端点，所以该区间至少会保留到当前查询结束，`T x` 同样满足要求。

综上，算法输出的所有查询结果正确，栈内元素始终互不相同，构造出的操作序列合法。

## 复杂度

每个入栈元素最多被压入和弹出各一次。

- 期望时间复杂度：$O(n)$；
- 空间复杂度：$O(n)$；
- 输出长度不超过 $2n$。

## 其他可行算法

### 维护下一次操作

还可以倒序预处理每个数值的下一次操作。正向模拟时，如果栈顶元素的下一次操作不是 `T`，就立即弹出；如果下一次是 `T`，则必须保留。

这种方法同样是期望 $O(n)$，但需要额外保存下一次出现位置。区间右端点写法只关心每次入栈对应的最后一次成功查询，实现更直接。

### 参考代码中的 map 与排序

使用 `map` 记录最近入栈编号，再把修改后的所有右端点排序，也能正确构造答案，时间复杂度为 $O(n\log n)$。本题总操作数达到 $10^6$，可以进一步用哈希表和 `del` 数组优化常数与复杂度。

### 暴力搜索

在相邻记录操作之间枚举插入多少次弹栈，并模拟所有查询，可以找到合法答案，但每个位置都有多个选择，复杂度是指数级，只适合小数据验证。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

using i32 = int;
using i64 = long long;
using i128 = __int128;
#define all(x) (x).begin(), (x).end()
#define dbg(x) cerr << #x << " = " << (x) << endl;

int T = 1, n, m, k, ans, cnt;

void solve() {
    cin >> n;
    vector<char> op(n + 1);
    vector<int> l(n), r(n), del(n + 1);
    unordered_map<int, int> id;
    id.reserve(2 * n);

    int tot = 0;
    for (int i = 1, x; i <= n; i++) {
        cin >> op[i] >> x;
        if (op[i] == '+') {
            l[tot] = r[tot] = i;
            id[x] = tot++;
        } else if (op[i] == 'T') {
            r[id[x]] = i;
        }
    }

    vector<int> stk;
    stk.reserve(tot);
    int p = 0;
    for (int i = 1; i <= n; i++) {
        if (p < tot && l[p] == i) stk.push_back(p++);
        while (!stk.empty() && r[stk.back()] <= i) {
            stk.pop_back();
            del[i]++;
        }
    }

    for (int i = 1; i <= n; i++) {
        cout << (op[i] == '+' ? '+' : '?');
        while (del[i]--) cout << '-';
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for(cin >> T; T--; solve());
    return 0;
}
```

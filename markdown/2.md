# 解题思路

## 1. 关键观察：价值最大化的充要条件

价值为每对相邻位置 $(P_1,P_2),(P_3,P_4),\dots$ 的差的绝对值之和。

先看**有 0 的对**（变量对）。设这些对共有 $E$ 个。把参与这些对的数字称为"相关数字"：

- 只有一边有数字的对（`1-固定对`）：固定数字称为**锚点**；
- 两边都是 0 的对（`0-对`）：两个空位都要填。

相关数字总数为 $2E$（锚点 + 缺失数字）。两边都有数字的对贡献是常数，可以忽略（只影响最大值，不影响方案数）。

对于任意一种填充，每对贡献 = 该对最大值 − 该对最小值。令：

- $M$ = 每对中"较大值"的集合（$E$ 个）
- $m$ = 每对中"较小值"的集合（$E$ 个）

则 $M \cup m$ = 相关数字，变量部分总价值 = $\sum M - \sum m$。

**最大值唯一**：$\sum M - \sum m$ 最大当且仅当 $M$ 是相关数字中最大的 $E$ 个（记为 **Top**），$m$ 是最小的 $E$ 个（记为 **Bottom**）。因为所有数字互不相同，这个划分是唯一的，且一定能实现（锚点和缺失数字的数量恰好匹配）。

因此：**每对变量对必须恰好含一个 Top 数和一个 Bottom 数**。

## 2. 计数

设：

- $E_0$：全 0 对的数量
- $E_1$：单边有数字的对的数量
- $E = E_0 + E_1$：变量对总数
- $a_R$：Top（最大 $E$ 个相关数字）中锚点的个数

Top 中缺失数字有 $E - a_R$ 个，Bottom 中缺失数字有 $E_0 + a_R$ 个。

分配方式：

1. 每个全 0 对选哪个位置放 Top：$2^{E_0}$ 种。
2. 把 $E - a_R$ 个 Top 缺失数字分配到需要的空位：$(E - a_R)!$ 种。
3. 把 $E_0 + a_R$ 个 Bottom 缺失数字分配到需要的空位：$(E_0 + a_R)!$ 种。

$$
\text{答案} = 2^{E_0} \cdot (E - a_R)! \cdot (E_0 + a_R)! \pmod{998244353}
$$

## 3. 求 $a_R$

相关数字 = $1 \sim 2N$ 中去掉"两边都有数字的对"里的数字。从 $2N$ 向下扫描，跳过两边都固定的数字，取前 $E$ 个，统计其中锚点的个数即为 $a_R$。

复杂度 $O(N)$ 每组。

## C++ 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll MOD = 998244353;
const int MAXN = 200000;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    vector<ll> fact(MAXN + 1), pow2(MAXN + 1);
    fact[0] = 1;
    pow2[0] = 1;
    for (int i = 1; i <= MAXN; i++) {
        fact[i] = fact[i - 1] * i % MOD;
        pow2[i] = pow2[i - 1] * 2 % MOD;
    }

    int T;
    cin >> T;
    while (T--) {
        int N;
        cin >> N;
        int M = 2 * N;
        vector<int> a(M);
        for (int i = 0; i < M; i++) cin >> a[i];

        vector<char> anchor(M + 1, 0), bothFixed(M + 1, 0);

        int E0 = 0, E1 = 0;
        for (int i = 0; i < M; i += 2) {
            int x = a[i], y = a[i + 1];
            if (x == 0 && y == 0) {
                E0++;
            } else if (x == 0) {
                E1++;
                anchor[y] = 1;
            } else if (y == 0) {
                E1++;
                anchor[x] = 1;
            } else {
                bothFixed[x] = 1;
                bothFixed[y] = 1;
            }
        }

        int E = E0 + E1;
        int aR = 0;
        int remaining = E;

        // 从大到小取 E 个相关数字，统计其中锚点数量
        for (int v = M; v >= 1 && remaining > 0; v--) {
            if (bothFixed[v]) continue;   // 两边都固定的对，不参与
            remaining--;
            if (anchor[v]) aR++;
        }

        ll ans = pow2[E0] * fact[E - aR] % MOD;
        ans = ans * fact[E0 + aR] % MOD;
        cout << ans << '\n';
    }

    return 0;
}
```

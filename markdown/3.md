# 题解

## 核心思路

每天开始先 `a += b`，再做操作。对于位置 `i`，第 `t` 天查询时它的 `a_i` 可以拆成三部分贡献：

1. **初始 `a_i`**：一直在，贡献 `a_i(0)`。
2. **初始 `b_i`**：每一天的 `a += b` 都会加一次，共 `t` 次，贡献 `t * b_i(0)`。
3. **第 `s` 天的 `b += x` 操作**：这次加上的 `x`，会在第 `s+1, s+2, ..., t` 天被加到 `a` 里，共 `t-s` 次，贡献 `(t-s)*x`。

所以：

```
a_i(t) = a_i(0) + t * b_i(0) + Σ (t - s) * x_s
```

区间求和：

```
Σ a_i(t) = Σa0 + t * Σb0 + t * Σx_s - Σ(s * x_s)
```

其中 `Σx_s` 是该区间内所有操作 `x` 的和，`Σ(s*x_s)` 是 `发生天数 * x` 的和。

因此维护两个**支持区间加、区间求和**的树状数组：

- `bitX`：每次操作 `1 l r x` 时，区间 `[l,r]` 加上 `x`；
- `bitSX`：每次操作时，区间 `[l,r]` 加上 `day * x`。

查询时直接套公式。所有运算用 `unsigned long long`，自动对 `2^64` 取模。

复杂度：`O((n + m) log n)`。

## 补全代码

```cpp
#include<bits/stdc++.h>
using namespace std;

using i32 = int;
using i64 = unsigned long long;
using i128 = __int128;
#define all(x) (x).begin(), (x).end()
#define dbg(x) cerr << #x << " = " << (x) << endl;

int T = 1, n, m, k, ans, cnt;

struct BIT {
    vector<i64> a, b;
    int n;

    BIT(int n) : n(n), a(n + 1), b(n + 1) {}

    // 区间加 val
    void rangeAdd(int l, int r, i64 val) {
        auto add = [&](int pos, i64 val) {
            for (int i = pos; i <= n; i += i & -i) {
                a[i] += val;
                b[i] += pos * val;
            }
        };
        add(l, val), add(r + 1, -val);
    }

    // 区间求和
    i64 rangeSum(int l, int r) {
        auto sum = [&](int x) {
            i64 ans = 0;
            for (int i = x; i; i -= i & -i) {
                ans += (x + 1) * a[i] - b[i];
            }
            return ans;
        };
        return sum(r) - sum(l - 1);
    }
};

void solve() {
    cin >> n >> m;

    vector<i64> a(n + 1), b(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i] >> b[i];

    vector<i64> prea(n + 1), preb(n + 1);
    for (int i = 1; i <= n; i++) {
        prea[i] = prea[i - 1] + a[i];
        preb[i] = preb[i - 1] + b[i];
    }

    BIT bitX(n), bitSX(n);   // bitX 存 x，bitSX 存 day * x

    for (i64 day = 1; day <= (i64)m; day++) {
        int op, l, r;
        cin >> op >> l >> r;

        if (op == 1) {
            i64 x;
            cin >> x;
            bitX.rangeAdd(l, r, x);         // 累加 x
            bitSX.rangeAdd(l, r, x * day);  // 累加 day * x
        } else {
            i64 res = (prea[r] - prea[l - 1])
                    + day * (preb[r] - preb[l - 1])
                    + day * bitX.rangeSum(l, r)
                    - bitSX.rangeSum(l, r);
            cout << res << '\n';
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for (cin >> T; T--; solve());
    return 0;
}
```

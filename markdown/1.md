我先把约束按对角线划分为“非负元素”和“负元素”。完整约束下，同号元素之间的结果是固定的，真正需要构造的部分只剩一个 0/1 比较矩阵。

```python
import sys
input = lambda: sys.stdin.readline().strip()
it = iter(sys.stdin.read().split())
SI = lambda: next(it)
II = lambda: int(SI())

fmax = lambda a, b: a if a > b else b
fmin = lambda a, b: a if a < b else b
out = []

def main():
    n, m = II(), II()

    # relation[i][j] = 1 表示和非负，= 2 表示和为负
    relation = [bytearray(n) for _ in range(n)]

    for _ in range(m):
        o, i, j = II(), II() - 1, II() - 1
        relation[i][j] = o
        relation[j][i] = o

    nonnegative = []
    negative = []

    # 对角线约束唯一确定每个数的正负性
    for i in range(n):
        if relation[i][i] == 1:
            nonnegative.append(i)
        else:
            negative.append(i)

    # 两个非负数之和一定非负，两个负数之和一定为负
    for i in range(n):
        for j in range(i, n):
            if relation[i][i] == relation[j][j]:
                expected = 1 if relation[i][i] == 1 else 2
                if relation[i][j] != expected:
                    out.append("NO")
                    return

    # 对每个负数，统计它与多少个非负数的和要求非负。
    # 绝对值越小，这个数量应该越大。
    count = [0] * n
    for v in negative:
        count[v] = sum(relation[u][v] == 1 for u in nonnegative)

    negative.sort(key=lambda v: count[v], reverse=True)

    answer = [0] * n

    # 将负数依次设为 -1, -2, ...
    for rank, v in enumerate(negative, 1):
        answer[v] = -rank

    # 若一个非负数与 k 个负数的和非负，则把它设为 k。
    # 此时这 k 个负数必须恰好是排序后的前 k 个。
    for u in nonnegative:
        k = sum(relation[u][v] == 1 for v in negative)
        answer[u] = k

        for rank, v in enumerate(negative):
            expected = 1 if rank < k else 2
            if relation[u][v] != expected:
                out.append("NO")
                return

    out.append("YES")
    out.append(" ".join(map(str, answer)))


for _ in range(II()):
    main()

print('\n'.join(map(str, out)))
```

**题解**

由对角线限制 `(i,i)` 可知：

- 若 `o=1`，则 `2a_i >= 0`，所以 `a_i >= 0`。
- 若 `o=2`，则 `2a_i < 0`，所以 `a_i < 0`。

因此所有位置被分成非负组和负数组。

同组之间的限制是固定的：

- 两个非负数之和一定非负，限制必须为 `1`。
- 两个负数之和一定为负，限制必须为 `2`。

如果不满足，直接输出 `NO`。

对于一个非负数 `a_u=x` 和负数 `a_v=-y`，其中 `x>=0,y>0`：

\[
a_u+a_v\ge 0 \iff x\ge y
\]

所以问题转化为给负数的绝对值排序。绝对值越小，它能与越多非负数满足“和非负”。因此按照每个负数拥有的 `o=1` 跨组限制数量降序排列，并依次赋值为：

\[
-1,-2,-3,\ldots
\]

如果某个非负位置与恰好 `k` 个负数要求和非负，就将它赋值为 `k`。此时排序后的前 `k` 个负数与它的和非负，其余负数与它的和为负。检查原限制是否正好符合这种前缀结构即可。

所有构造出的数绝对值不超过 `n<=1000`。

时间复杂度为 `O(n^2+m)`，空间复杂度为 `O(n^2)`。

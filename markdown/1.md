定义 f_k(m)：有 m 个连续位置，随便选若干个、任意两个间隔 ≥ k 的方案数
全部 n 个位置随便选：f_k(n) 种。
要求 x 不选 = 总方案 − x 被选 的方案。
x 被选时，左右两边互不影响：
左边离 x 至少 k 的位置只剩 1..x−k，共 x−k 个；
右边只剩 x+k..n，共 n−x−k+1 个（不够 0 个时视为 1 种：只能空选）。
所以答案 = f_k(n) − f_k(x−k) × f_k(n−x−k+1)（取模、取正）。
怎么求 f_k(m)：两种办法
递推（适合小 k）：看第 m 个位置
不选它 → 前 m−1 个随便选：f(m−1)
选它 → 前面 m−k 个随便选：f(m−k)（m<k 时这一项是 1）
即 f[m] = f[m−1] + f[m−k]，一次 O(n) 就能算完 f[0..n]，之后每个询问 O(1) 回答。
组合数公式（适合大 k）：选 j 个位置，把每两个之间的 k−1 个空隙"压缩"掉，等价于从 m−(j−1)(k−1) 个里选 j 个：
f_k(m) = Σⱼ C(m−(j−1)(k−1), j)，j 大约到 m/k 就停了，k 大时项数很少。
根号分治
k ≤ 1000：每个出现过的 k 跑一遍 DP 表（O(MAXN)），一次回答它所有询问；
k > 1000：每个询问用公式求和（O(MAXN/k) ≤ 100 项）。
总复杂度约 O(B·MAXN + Σq·MAXN/B)，B=1000。实测极限数据（T=1e4，Σn≈Σq≈1e6，MAXN=1e5）运行 1.31 秒。

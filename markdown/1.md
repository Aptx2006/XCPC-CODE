设一次操作前的数组为 $x$，操作后为 $y$。为了准确得到 $y$，被选择的位置必须恰好是所有满足 $x_i\ne y_i$ 的位置。
这些位置在操作前的元素和为奇数，等价于：
$$\#\{i\mid x_i=1,\ y_i=0\}$$
是奇数。也就是说：

可以通过一次操作从 $x$ 变成 $y$，当且仅当从 $1$ 变成 $0$ 的位置数量为奇数。

特殊的不可达状态

如果 $a$ 全为 0，则无法执行任何操作，因为任意子序列的元素和都是 0。
如果 $b$ 全为 1，则无法通过一次操作进入 $b$。最后一次操作所选择的只能是当前为 0、目标为 1 的位置，其元素和必然为 0。

所以，当 a != b 时：

a 全为 0，无解；
b 全为 1，无解。

最少操作次数

如果 a == b，答案是 0。
统计满足 a[i] == 1 && b[i] == 0 的位置数量 cnt。
如果 cnt 是奇数，可以直接选择所有不同的位置，答案是 1。
否则，在排除上述不可达状态后，答案一定是 2。

第四点可以用模 $2$ 线性方程证明。寻找中间数组 $c$，需要满足：
$$a\cdot c = (\#1(a)+1)\bmod 2$$
以及
$$\overline b\cdot c=1$$
因为 a 非零且 $\overline b$ 非零：

如果 $a\ne\overline b$，两个系数向量在 $\mathbb F_2$ 上线性无关，方程一定有解；
如果 $a=\overline b$，由于一次操作不可行，a 中 1 的数量为偶数，此时两个方程相同，也有解。

因此答案只可能是 -1, 0, 1, 2。

## 题解：状态压缩 + 逐维转移

### 核心思路

将一整行的颜色状态编码成一个 \(m\) 进制整数。

一行共有 \(m^q\) 种状态，最大为：

\[
4^8=65536
\]

设 `dp[s]` 表示当前行状态为 \(s\) 的方案数。

如果直接枚举上一行状态和当前行状态，复杂度为 \(O(p\cdot m^{2q})\)，无法通过。

对于固定的当前行状态 \(s\)，上一行状态 \(t\) 必须满足：

\[
s_j\ne t_j,\quad 0\le j<q
\]

单个位置上的转移矩阵为：

\[
A_{x,y}=[x\ne y]
\]

整行的纵向转移相当于在每个位置上依次应用这个转移矩阵。

对于某一位，将其他位固定。假设这一位取各种颜色时的方案数为：

\[
v_0,v_1,\ldots,v_{m-1}
\]

那么转移后颜色为 \(c\) 的方案数为：

\[
v'_c=\sum_{x\ne c}v_x
=\left(\sum_xv_x\right)-v_c
\]

因此可以依次对每一位进行上述变换。一次整行转移的复杂度是：

\[
O(qm^q)
\]

完成纵向转移后，再将存在左右相邻颜色相同的非法行状态清零即可。

---

### 正确性说明

每次对第 \(j\) 位执行变换时，新的状态值会累加所有第 \(j\) 位颜色不同、其余位暂时不变的旧状态。

依次处理全部 \(q\) 位后，一个旧状态 \(t\) 会被计入新状态 \(s\) 当且仅当：

\[
\forall j,\ t_j\ne s_j
\]

这正好满足上下相邻格子的颜色不能相同。

随后将当前行中左右相邻颜色相同的状态清零，保证行内相邻格子的颜色也不同。因此，动态规划统计的恰好是所有合法填放方案。

---

### 复杂度

状态数为 \(m^q\)。

- 时间复杂度：

\[
O(pqm^q)
\]

- 空间复杂度：

\[
O(m^q)
\]

最大计算量约为 \(100\times 8\times 4^8\)，可以通过。

---

```cpp
#include <bits/stdc++.h>
using namespace std;

using i32 = int;
using i64 = long long;
using i128 = __int128;
#define all(x) (x).begin(), (x).end()
#define dbg(x) cerr << #x << " = " << (x) << endl;

int T = 1, n, m, k, ans, cnt;
int dx[] = {-1, 1, 0, 0};
int dy[] = {0, 0, -1, 1};

const i64 mod = 998244353;

void solve() {
    int p, q;
    cin >> p >> q >> m;

    vector<int> a(q), b(q);
    for(auto &x: a) cin >> x;
    for(auto &x: b) cin >> x;

    vector<int> pw(q);
    pw[0] = 1;
    for(int i = 1; i < q; i++) {
        pw[i] = pw[i - 1] * m;
    }

    int states = pw[q - 1] * m;

    auto encode = [&](const vector<int> &v) {
        int id = 0;
        for(int i = 0; i < q; i++) {
            id += v[i] * pw[i];
        }
        return id;
    };

    vector<bool> valid(states, true);

    for(int id = 0; id < states; id++) {
        int x = id;
        int last = -1;

        for(int i = 0; i < q; i++) {
            int color = x % m;
            x /= m;

            if(i && color == last) {
                valid[id] = false;
                break;
            }

            last = color;
        }
    }

    vector<i64> dp(states);
    dp[encode(a)] = 1;

    for(int row = 1; row < p; row++) {
        for(int pos = 0; pos < q; pos++) {
            int step = pw[pos];
            int block = step * m;

            for(int l = 0; l < states; l += block) {
                for(int offset = 0; offset < step; offset++) {
                    i64 sum = 0;

                    for(int color = 0; color < m; color++) {
                        int id = l + offset + color * step;
                        sum += dp[id];
                    }

                    sum %= mod;

                    for(int color = 0; color < m; color++) {
                        int id = l + offset + color * step;
                        dp[id] = (sum - dp[id] + mod) % mod;
                    }
                }
            }
        }

        for(int id = 0; id < states; id++) {
            if(!valid[id]) dp[id] = 0;
        }
    }

    cout << dp[encode(b)] << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for(; T--; solve());
    return 0;
}
```

对于样例，中间一行必须同时与第一行、最后一行逐列不同，并且自身左右不同，共有 \(3\) 种合法状态，因此答案为 `3`。

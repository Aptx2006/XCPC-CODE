## 题意
有 $x$ 张蓝色牌、$y$ 张红色牌和一个初始为 $1$ 的变量 $k$ , 对于每次出牌：
- 若打出了一张蓝色牌，则会令 $k$ 增加 $1$
- 若打出了一张红色牌，设出牌后你的剩余手牌数为 $p$，则会造成 $k \times p$ 点伤害，然后将 $k$ 设为 $1$

现给定 $x,y$ 求打出所有牌后能造成的最大伤害。

## 分析
只有红色牌能造成伤害，并且和两个因素有关：
1.上一张红色牌之后出了多少张蓝色牌
2.还剩多少张牌
所以考虑将红色牌看成插板，对蓝色牌进行插板分块，类似这样：

$$⬛️|⬛️|⬛️|....⬛️|⬛️|⬛️$$

$y$ 张红色牌可以分成 $y+1$ 个蓝色块不妨设每块有 $a_i$ 张蓝色牌，显然有

$$\sum_{i=1}^{y+1} a_i = x$$
此时的红牌 $i$ 的伤害等于 系数 $\times$ (剩余红牌+剩余蓝牌)，即：

$${(a_i + 1)} \times {(y - i + \sum_{j = i+1}^{y+1} a_j)}$$
此时聪明的我发现，为了统一形式，可以将 ${y - i}$ 提到 $\sum_{}$ 中：

$${(a_i + 1)} \times {(\sum_{j = i+1}^{y}(a_j + 1) + a_{y+1})}$$

不妨设

$$b_i = \begin{cases}
a_i + 1 & i <= y \\\\
a_{y+1} & i = y
\end{cases}$$

这样设有很多好处，可以统一上面的式子，并且这个 $b_i$ 是有实际含义的，它代表这样一个部分：$$⬛️|$$ 也就是一块蓝色加上一张红色，最后一块正好没有红色，所以不用加一，而且可以利用不等式去推出答案，不过这是后话了，想到这一步的时候我真觉得我帅麻了

此时伤害的计算公式可整理为：

$${b_i} \times {\sum_{j = i+1}^{y+1} b_j}$$

不要忘了我们只考虑了红牌 $i$，现在考虑总伤害：


$${\sum_{i = 1}^{y} b_i} \times {\sum_{j = i+1}^{y+1} b_j} = \sum_{1\le i<j\le y+1} b_i \times b_j$$

由数学公式我们知道上式等于下面这个式子：

$${\frac{1}{2}({\sum_{i = 1}^{y + 1} b_i }^ 2} - \sum_{i = 1}^{y+1} b_i ^ 2)$$

注意到：

$${\sum_{i = 1}^{y + 1} b_i } =\sum_{i = 1}^{y}(a_i + 1) + a_{y+1} = \sum_{i = 1}^{y+1} a_i + y = x + y$$

所以伤害计算式为：

$${\frac{1}{2}({(x + y)}^ 2} - \sum_{i = 1}^{y+1} b_i ^ 2)$$


所以我们只需要让 $\sum_{i = 1}^{y+1} b_i ^ 2$ 最小，就能让总伤害最大，由于 $\sum_{i = 1}^{y+1} b_i = x + y$ 为定值，考虑到均值不等式，平方平均数在各项均等时取得最小值，那么我们只需要让 $x + y$ 均分给 $y + 1$ 项即可，多出来的匀一下，最终可得到伤害最大值

## 代码

```cpp
void solve() {
    i64 x, y;
    cin >> x >> y;
    i64 sum = x + y;
    i64 b = sum / (y + 1), c = sum % (y + 1);
    i64 dif = c * (b + 1) * (b + 1) + (y + 1 - c) * b * b;
    cout << (sum * sum - dif) / 2 << '\n';
}
```

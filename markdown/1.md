### 题解分析

#### 1. 括号序列合法性转化
题目要求所选多边形的**任意一个**带有左括号的顶点，在顺时针或逆时针方向上的括号序列都是合法的。
若我们将左括号 `(` 视为 $+1$，右括号 `)` 视为 $-1$。一个长度为 $m$ 的序列在任意方向均从任一左括号开始合法，意味着全局的前缀和最小值只能出现在左括号的前面（或右边，对应逆时针）。可以严格证明，唯一满足该条件的序列是**严格交替的括号序列**，即 `()()()()...`。
这意味着：
1. 凸多边形的顶点上的括号类型必须是严格交替的 `0, 1, 0, 1...`。
2. 凸多边形的顶点数 $m$ 必然是偶数。
3. 题目要求 $m \ge 3$，因 $m$ 是偶数，实际要求为 $m \ge 4$。

#### 2. 转换为动态规划问题
现在问题转换为：在给定的点集中，选出 $m \ge 4$ 个点构成凸多边形，且相邻两点的括号类型不同的方案数。

利用凸多边形的性质：一个按逆时针 (CCW) 排列的严格凸多边形，其有向边的极角在 $[-\pi, \pi)$ 中严格递增，并且刚好环绕一圈（即跨越边界恰好一次）。
因此我们可以这样做：
1. 建立所有满足 $type[u] \neq type[v]$ 的有向边 $u \to v$。
2. 将所有有向边按极角排序。
3. 按极角顺序进行动态规划。我们设 `dp[v][c]` 表示当前构成了一条以 $c$ 为起点、以 $v$ 为终点的凸包极角递增链的方案数。
4. 由于我们限制了链中使用的边都是不同类型的顶点相连，因此构成的环天然满足类型严格交替。
5. 转移方程：遍历极角排序后的每一条边 $u \to v$，它可以接在任何终点为 $u$ 的链的后面（起点 $c$ 保持不变），即 `dp[v][c] += dp[u][c]`。并且它自己也可以作为一条新链的开始，即 `dp[v][u] += 1`。

#### 3. 处理 2-gon 和防止重复计数
按照极角处理完所有边后，`dp[i][i]` 的和就是所有环的个数。
但是，由于我们在图里加入了正反两向的边，所有符合 $type[u] \neq type[v]$ 的两点对也会互相连边，构成一个退化的二角形 (2-gon)，其也会被统计恰好一次。由于题目要求 $m \ge 3$，我们需要从总数中减去这部分二角形的贡献，即 `n0 * n1`（类型为 0 的点数乘类型为 1 的点数）。

#### 4. 复杂度分析与代码优化
- 边数最大可达 $E = 2 \times N_0 \times N_1 \le N^2/2$。排序时间 $O(E \log E)$ 非常快。
- 动态规划的过程如果单纯暴力转移是 $O(E \times N)$。我们可以通过维护一个每个点当前拥有的起点列表 `active_c` 来大幅减小常数。为了使缓存局部性达到最佳，我们将 DP 状态设置为 `dp[终点][起点]`，这让内层循环成为连续内存访问。这足以在非常短的时间内通过本题。

### C++ AC 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

const int MOD = 998244353;

struct Point {
    long long x, y;
    int type;
};

struct Edge {
    int u, v;
    long long dx, dy;
    // 严格按极角排序，无需浮点运算以免产生精度问题
    bool operator<(const Edge& o) const {
        auto half = [](long long x, long long y) {
            return (y > 0 || (y == 0 && x > 0)) ? 0 : 1;
        };
        int h1 = half(dx, dy);
        int h2 = half(o.dx, o.dy);
        if (h1 != h2) return h1 < h2;
        // 同半平面内利用叉积判左右
        long long cross = dx * o.dy - dy * o.dx;
        return cross > 0;
    }
};

int dp[505][505];
bool has_active[505][505];
vector<int> active_c[505];

void solve() {
    int n;
    if (!(cin >> n)) return;
    vector<Point> pts(n + 1);
    int n0 = 0, n1 = 0;
    for (int i = 1; i <= n; i++) {
        cin >> pts[i].x >> pts[i].y >> pts[i].type;
        if (pts[i].type == 0) n0++;
        else n1++;
    }

    vector<Edge> edges;
    edges.reserve(2 * n0 * n1);
    // 只保留括号类型不同的点对构成的边
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (pts[i].type != pts[j].type) {
                edges.push_back({i, j, pts[j].x - pts[i].x, pts[j].y - pts[i].y});
            }
        }
    }

    // 按极角逆时针排序
    sort(edges.begin(), edges.end());

    // 初始化 DP
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            dp[i][j] = 0;
            has_active[i][j] = false;
        }
        active_c[i].clear();
    }

    // 在排好序的边上跑 DP
    for (const auto& e : edges) {
        int u = e.u;
        int v = e.v;
      
        // 尝试用已有极角递增链承接新边 e
        for (int c : active_c[u]) {
            if (c == u) continue; // 避免自环继续拓展破坏简单多边形性质
            int &nxt = dp[v][c];
            if (!has_active[v][c]) {
                has_active[v][c] = true;
                active_c[v].push_back(c);
            }
            nxt += dp[u][c];
            if (nxt >= MOD) nxt -= MOD;
        }
      
        // 此边自己作为一条新链
        int &nxt_u = dp[v][u];
        if (!has_active[v][u]) {
            has_active[v][u] = true;
            active_c[v].push_back(u);
        }
        nxt_u += 1;
        if (nxt_u >= MOD) nxt_u -= MOD;
    }

    // 统计能闭合产生环的链的总量
    long long total_cycles = 0;
    for (int i = 1; i <= n; i++) {
        total_cycles = (total_cycles + dp[i][i]) % MOD;
    }

    // 减去所有不合法的退化二角形数量 (每对异类点构成一个合法的2-gon循环并恰好被计算一次)
    long long to_sub = (1LL * n0 * n1) % MOD;
    long long ans = (total_cycles - to_sub + MOD) % MOD;

    cout << ans << "\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```
